# arthadesk-bot (अपडेटेड)

## Render में डालने के लिए Environment Variables
- ANGEL_API_KEY, ANGEL_CLIENT_ID, ANGEL_MPIN, ANGEL_TOTP_SECRET  (पहले जैसे)
- DASH_PASSWORD  → **ज़रूरी**. डैशबोर्ड का पासवर्ड (यूज़रनेम डिफ़ॉल्ट: admin, बदलना हो तो DASH_USER)
- ALLOW_LIVE     → **सेट न करें**. YES डालने पर ही LIVE मोड चालू हो सकता है

## क्या बदला
1. API कॉल सिर्फ़ बाज़ार के घंटों में (सोम–शुक्र 9:15–3:30) और सिर्फ़ तब जब एंट्री-विंडो हो या पोजीशन खुली हो
2. रेट-लिमिट एरर पर 20→40→80→160→300 सेकंड का बैकऑफ़, और लॉगिन बार-बार नहीं ठोका जाता
3. VWAP अब रोज़ 9:15 से नया (पहले 4 दिन का मिला हुआ था); वॉल्यूम और पिछली 3 कैंडल का हाई/लो भी उसी दिन के
4. पेपर P&L में ब्रोकरेज/टैक्स (अनुमान) और स्लिपेज शामिल; दरें strategy_engine.py के ऊपर बदली जा सकती हैं
5. रोज़ नई तारीख़ पर P&L, लॉग और डेली-लॉस रीसेट
6. डैशबोर्ड पर पासवर्ड; LIVE मोड ALLOW_LIVE=YES के बिना बंद; पोजीशन खुली हो तो मोड नहीं बदलता
7. लाइव ऑर्डर फेल हो तो ग़लत पोजीशन नहीं बनती; एग्ज़िट फेल हो तो पोजीशन खुली रहकर दोबारा कोशिश होती है
8. "ट्रेड" की गिनती अब बंद हुए ट्रेड की है (पहले एंट्री+एग्ज़िट दोनों गिने जाते थे)

## सीमाएँ
- लाइव मोड में एक्सचेंज-साइड स्टॉप-लॉस ऑर्डर नहीं है: बॉट/सर्वर बंद हुआ तो पोजीशन बिना SL रह सकती है
- SEBI नियम (अप्रैल 2026 से): API ऑर्डर के लिए ब्रोकर के पास रजिस्टर्ड स्टैटिक IP चाहिए
- यह सिर्फ़ शैक्षणिक/प्रयोग के लिए है, निवेश सलाह नहीं
